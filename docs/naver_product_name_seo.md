## 1. 글자 수 한도

| 항목 | 값 | 비고 |
|------|-----|------|
| **권장** | 50자 내외 | 네이버 권장값 — 이 이상은 "남용" 판단 |
| **최대** | 100자 | 시스템 한도 |
| 우리 시스템 한도 | **50자 / 100바이트** | 권장값 기준으로 truncate |

**계산 규칙**: 11번가는 한글 2바이트로 환산하지만, 네이버는 **글자 수 기준**이 1차. 다만 안전한 호환을 위해 글자수 ≤ 50 AND 바이트수 ≤ 100 양쪽 모두 만족시킴.

```python
NAVER_MAX_CHARS = 50
NAVER_MAX_BYTES = 100  # 한글 2바이트 환산
```

## 2. 상품명 구조 (필드 순서)

네이버는 다음 순서로 키워드 배치를 권장:

```
1. 브랜드/제조사
2. 시리즈
3. 모델명(코드)
4. 상품 유형(형태)
5. 색상
6. 소재
7. 패키지 내용물 수량
8. 사이즈
9. 성별/나이 표현
10. 속성 (용량 / 무게 / 연식 / 호수 등)
```

**중요**: 11번가는 [브랜드][상품명][홍보문구] 3-part 입력이지만, 네이버는 **단일 텍스트 필드**. 위 순서대로 자연스러운 문장처럼 이어 붙이는 게 핵심.

### 카테고리별 예시 패턴

```
의류:    [브랜드] [성별] [계절] [소재] [상품유형] [색상] [사이즈]
         → "유니클로 남성 여름 린넨 반팔 셔츠 네이비 L"

식품:    [브랜드] [상품명] [원재료/원산지] [중량] [패키지수량]
         → "정관장 홍삼정 6년근 100g 1세트"

가전:    [브랜드] [모델명] [상품유형] [핵심스펙] [색상]
         → "삼성 BESPOKE 비스포크 냉장고 4도어 875L 화이트"

생활용품: [브랜드] [재질] [상품명] [용량/사이즈] [패키지수량] [용도]
         → "락앤락 스테인리스 텀블러 500ml 2개입 직장인"
```

## 3. 금지 / 지양 항목

### 3.1 절대 금지 (포함 시 신뢰도 페널티)

| 분류 | 예시 |
|------|------|
| **수식어** | "고급", "프리미엄", "최고급", "프리미엄급", "명품급" |
| **홍보문구** | "인기", "베스트", "베스트셀러", "1위", "1등", "BEST", "신상", "신상품" |
| **과장 표현** | "최저가", "최고", "최강", "정품", "공식", "100%", "기적의", "마법의" |
| **혜택/할인** | "할인", "쿠폰", "이벤트", "사은품", "무료배송", "당일발송", "당일출고" |
| **카테고리명 반복** | (카테고리 설정으로 충분) — 카테고리와 동일 단어 |
| **가격 표기** | 별도 필드 사용 |
| **배송 조건** | 별도 필드 사용 |
| **셀러/쇼핑몰명** | 자체 스토어명 삽입 금지 |

### 3.2 특수문자 (허용/금지)

```
허용: ( )  -  ·  [ ]  /  &  +  ,  ~  .
금지: ! ? @ # $ * ★ ☆ ♥ ♡ ◆ ◇ ■ □ ※ ▶ ◀ ▲ ▼ → ← ↑ ↓
     ㅋ ㅎ ㅠ ㅜ ⓒ ® ™ 이모지(전체)
```

**구현**: 허용 집합 외 모두 제거.

### 3.3 언어

- **허용**: 한글, 영문 (대소문자), 숫자
- **금지**: 한자, 일본어(가나), 기타 문자

### 3.4 중복

- **브랜드명은 1회만** 표기
- **동일 단어 중복 금지** (네이버 알고리즘이 스팸 판단)
  - 예: "텀블러 텀블러 보온 텀블러" → "텀블러 보온 500ml"

## 4. 키워드 전략

### 4.1 롱테일 우선

| 키워드 유형 | 월 검색량 예시 | 경쟁 | 전략 |
|-----------|------------|-----|-----|
| 메인 키워드 | 디퓨저 (150만) | 매우 높음 | ❌ 단독 사용 회피 |
| 세부 키워드 | 대용량 디퓨저 (2만) | 중간 | ✅ 메인 노출 가능 |
| 롱테일 | 차량용 대용량 디퓨저 (수천) | 낮음 | ✅ 다중 쿼리 노출 |

**원칙**: 검색량은 낮아도 **구체적/조합된 키워드**가 상위 노출에 더 유리.

### 4.2 자연스러운 문장 구조

- ❌ 키워드 나열형: "디퓨저 차량용 대용량 향수 차박 캠핑 선물용"
- ✅ 자연스러운 형태: "차량용 대용량 디퓨저 500ml 차박 캠핑 선물용"

네이버 AI 검색 시스템(2026년 기준)은 **자연스러운 문장 구조 + 키워드 분포 + 문맥적 연결성**을 긍정 평가.

### 4.3 핵심 키워드 위치

- **앞쪽 25자 이내**에 가장 중요한 키워드 (브랜드 + 핵심명사 + 핵심스펙)
- 후반부는 보조 속성 (색상, 사이즈, 용도, 시즌)

## 5. 네이버 쇼핑 랭킹 알고리즘 (참고)

상품명 SEO는 아래 3축 중 **적합도**와 **신뢰도**에 직접 영향:

### 적합도 (Relevance) — 검색의도 ↔ 상품정보 일치도
| 필드 | 가중치 |
|------|--------|
| **상품명** | 가장 큼 |
| 카테고리 | 큼 |
| 브랜드/제조사 | 중간 (브랜드 검색 시 매우 큼) |
| 속성/태그 | 중간 |

### 인기도 (Popularity) — 상품명 작성과 무관 (참고)
- 클릭 (최근 7일), 찜, 판매, 리뷰, 최신성

### 신뢰도 (Trust) — 페널티 기반 (감점 요소)
- **상품명 SEO 준수도** ← 본 문서의 룰 위반 시 감점
- 네이버 쇼핑 페널티 (어뷰징 적발 시)

## 7. 우리 시스템 구현 요약

`backend/smartstore/naver_name_generator.py`의 핵심 책임:

1. **LLM 프롬프트**: 위 룰을 system prompt 에 명시 + few-shot 예시 2~3개
2. **후처리**:
   - `_strip_forbidden_symbols()` — 허용 집합 외 특수문자 제거
   - `_strip_forbidden_keywords()` — 금지어/홍보문구 substring 제거
   - `_dedupe_tokens()` — 동일 토큰 중복 제거 (브랜드명 1회만 유지)
   - `_strip_company_prefix()` — `(주)`, `주식회사` 등 제거
   - `_truncate_to_naver_limit()` — 50자 / 100바이트
3. **유효성 검증**: 결과가 4자 미만이면 reject, 다른 모델 fallback
4. **DB 저장**: `naver_my_product.naver_product_name` 컬럼 + `synced_at`
