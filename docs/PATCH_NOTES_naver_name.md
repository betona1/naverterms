# 네이버 상품명수정 패치 노트 (상품명수정 네이버)

> 네이버 상품명 AI 생성/컨펌 파이프라인의 버전별 패치 기록.
> 각 버전마다 **지적된 잘못된 프롬프트/동작** + **적용한 수정**을 명시한다.

---

## v1.02 (2026-05-26)

### 지적된 문제
1. **정규식 경계 누락** — v1.01 의 단어 경계 `(^|\s)X(?=\s|$)` 가 괄호/슬래시/하이픈을 경계로 인식 못함 → `(소꿉놀이 세트)`, `(1세트)` 등 잔존 4,468건.
2. **'1개' 잘못된 evidence** — `combined_option` 의 "1개" 같은 단순 단위 카운트를 set evidence 로 오인 → 세트 안전망 미작동.
3. **`N세트` 숫자+세트 패턴 누락** — `1세트`, `2세트` 같은 형태가 노이즈 패턴에 없었음.

### 적용한 수정
1. **boundary 교체** — `(?<![가-힣a-zA-Z0-9])X(?![가-힣a-zA-Z0-9])` 로 변경 → 한글/영숫자가 인접한 경우만 합성어 보호, 그 외 모든 경계(괄호/슬래시/하이픈/쉼표) 인식. SET·COLOR 안전망 모두 적용.
2. **evidence 엄격화** — `\d+\s*개` 무조건 매치 제거. `[2-9]\d*\s*개\s*(세트|묶음|입|팩|박스|세|개입)` 패턴 또는 `\d+\s*(팩|박스)` 동반시만 evidence 인정. 단순 "1개"는 evidence 미포함.
3. **`\d+세트` 노이즈 추가** — `1세트, 2세트, 10세트` 등도 단서 없으면 제거.

### 영향 범위 / 마이그레이션
- 적용 전 잔여 세트 4,468건 / 색상(블루) 313건. v1.02 일괄 재적용으로 추가 정리.
- 모든 스냅샷은 v1.00 이전까지 그대로 보존 → 롤백 가능.

## v1.01 (2026-05-26)

### 지적된 문제
1. **세트 할루시네이션** — 단일 상품인데 LLM 이 상품명에 "세트", "1개 세트", "묶음", "패키지", "N개입", "N개세트" 류를 자의적으로 박음. **64,077건** 영향 확인.
   - 원본 `product_name`, `option1_values`, `combined_option`, `keywords` 그 어디에도 세트 단서 없음에도 LLM 이 "검색 노출 다양화" 명목으로 박은 것으로 추정.
2. **색상 할루시네이션** — `option1_values` 에 없는 색상이 상품명에 박힘. **15,724건** 영향 확인.
   - 옵션/원본/키워드 어디에도 단서 없는 색상(블랙·화이트·네이비 등 36개 단어)이 비전 추측 단독으로 박힘.

### 적용한 수정
1. **`naver_name_generator.postprocess()` 에 SET-안전망 추가** — 원본/옵션/키워드/속성 어디에도 세트 단서가 없으면 LLM 출력의 `세트/묶음/패키지/N개입/N개세트/1+1/2+1` 표현을 후처리에서 자동 제거.
2. **`naver_name_generator.postprocess()` 에 COLOR-안전망 추가** — 원본/옵션/키워드/속성/명시된 비전옵션 어디에도 단서 없는 색상 토큰은 후처리에서 자동 제거.
3. **`_SYSTEM_PROMPT` 강화** — `[절대 금지]` 섹션에 "원본/옵션에 명시되지 않은 세트·색상 단어 박지 마라" 명시.
4. **모달 UI** — 헤더에 버전 라벨 `상품명수정 네이버 v1.01` 표시.

### 영향 범위 / 마이그레이션
- 영향 상품 식별 SQL: `backend/sql/naver_name_audit.sql` 참고
- 재생성 큐 등록: 일괄 후처리(`naver_name_repair.py`) 로 LLM 호출 없이 후처리만 재적용 가능.
